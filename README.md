# Automated-Network-Request-Management - Servicenow

> A ServiceNow solution for managing network requests through a structured and automated workflow.

---

### PROJECT

**Project Type:** ServiceNow Automation

**Platform:** ServiceNow

**Primary Tools:** Service Catalog, Flow Designer, Service Portal

**Status:** Completed

---

### WHAT THIS PROJECT DOES

The project provides a centralized way to handle network-related requests. Users can submit their requirements through a Service Catalog item, while approvals, notifications, fulfillment activities, and status updates are managed through an automated workflow.

---

### INCLUDED IN THE SOLUTION

**Request Management**

* Network Request catalog item
* Request details and validation
* Dynamic form fields

**Process Automation**

* Approval handling
* Automated notifications
* Fulfillment task creation
* Request status updates

**Access & Tracking**

* Role-based access
* Controlled record access
* Request monitoring and tracking
